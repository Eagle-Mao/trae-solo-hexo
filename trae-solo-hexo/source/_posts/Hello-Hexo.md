## 什么是 Hexo？

Hexo 是一个快速、简洁且高效的静态博客框架。基于 Node.js 驱动，支持 Markdown 语法，可以快速生成静态网页。

## 主要特性

- **快速生成**：强大的生成引擎，毫秒级完成编译
- **Markdown 支持**：支持 GitHub Flavored Markdown
- **主题系统**：丰富的主题生态
- **插件系统**：灵活的插件扩展

## 代码示例

```javascript
console.log('Hello, Hexo!');

const hexo = {
  name: 'Hexo',
  version: '8.0.0',
  description: 'A fast, simple & powerful blog framework'
};

console.log(`Welcome to ${hexo.name} v${hexo.version}`);
```
