为什么要写博客？在这个信息爆炸的时代，写博客似乎是一件”吃力不讨好”的事情。但我认为，写博客的价值远超想象。 写博客的五大理由1. 知识沉淀 教是最好的学。 当你尝试把一个知识点写出来的时候，你会发现自己理解的盲区。写作逼迫你把模糊的概念变得清晰。 2. 建立个人品牌一篇好的技术文章就是一张名片。它能让同行认识你，让招聘方了解你。 3. 帮助他人你踩过的坑，写出来的解决方案，可能正是别人苦苦寻找的答案。 4. 提升表达能力写作是一种结构化思考的训练。经常写博客的人，在沟通和表达上往往更加清晰。 5. 记录成长回头看自己几年前写的文章，你会惊讶于自己的成长。博客就是最好的成长日记。 如何开始？选择平台 静态博客：Hexo、Hugo、Jekyll 动态博客：WordPress、Typecho 平台托管：掘金、知乎、CSDN 选择主题选择一个你喜欢的主题，让写作更有动力。比如我选择了安知鱼主题，它的中国风设计让我爱不释手。 坚持输出 不必追求完美，先写出来 保持节奏，比如每周一篇 从笔记开始，逐步完善 我的博客搭建历程 选择 Hexo 作为博客框架 使用 GitHub Pages 免费 ...
